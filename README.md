## Elementor Pro Vorlage importieren

1. Lade die Datei [`elementor-hover-card.json`](elementor-hover-card.json) auf deinen Rechner herunter.
2. Öffne im WordPress-Backend **Templates → Gespeicherte Vorlagen** (Elementor).
3. Klicke auf **Importieren**, wähle die JSON-Datei aus und bestätige.
4. Die Vorlage „Futuristische Hover Card“ steht dir danach in Elementor zur Verfügung und kann per Drag-and-drop in jede Seite eingefügt werden.
5. Der komplette HTML-, CSS- und JavaScript-Code ist bereits in der Vorlage eingebettet. Du musst keine zusätzlichen Dateien nachladen – passe einfach Texte, Farben und Inhalte direkt in Elementor an.
